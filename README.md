# Student Grade Calculator

A simple and user-friendly web application to calculate student marks, total, percentage, grade, and pass/fail status.

## Features

- Student name input
- Five subject marks input
- Total marks calculation
- Percentage calculation
- Automatic grade calculation
- Pass/Fail result
- Reset option
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

student-grade-calculator/

├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter the student name and marks.
5. Click the calculate button to view the result.

## Grade System

- 90–100 → A+
- 80–89 → A
- 70–79 → B
- 60–69 → C
- 50–59 → D
- Below 50 → F

## Pass Criteria

A student must score at least 35 marks in every subject to pass.
